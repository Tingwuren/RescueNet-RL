## 1.1.4 方案生成

基于三层架构标准化配置，开发自动化组网方案生成引擎，打通**架构定义 → 场景/模式规则解析 → 五阶段方案组装 → 交付物导出**全链路，实现一键生成可直接指导现场部署的结构化组网方案，确保架构设计快速转化为可执行成果。

组网方案由 `deployment/plan_builder.py` 读取三层架构、灾害场景与组网模式配置后组装；`deployment/export_plan.py` 负责写入 JSON 并调用 `export_deployment_docs.py` 导出 01–04 标准化表格。核心逻辑如下：

```python
def build_network_plan(scenario_id: str, network_mode: str) -> Dict[str, Any]:
    scenario = load_scenario(scenario_id)           # scenarios/*.yaml
    arch = load_architecture()                     # L1/L2/L3 + comm_modes
    mode_data = load_network_mode(network_mode)     # mode_config + deploy_rules + topology_template
    phased = load_phased_deploy()                  # 5 步生成流程（设计文档 8.3.1 表 8.2）
    rl_info = parse_rl_output(scenario_id)         # 可选读取 HMARL checkpoint

    # 阶段 1：全局设备清单生成
    nodes, residual_count, emergency_count = _build_nodes(...)

    # 阶段 2：区域资源调度
    regional_tasks = split_tasks(n_regions, nodes, business_tasks)

    plan = { ... nodes, phases, deploy_priority, rl_enhancement ... }

    # 阶段 3：设备点位生成
    assign_grid_placements(plan, ...)              # grid_placement.py

    # 阶段 4：三级拓扑构建
    plan["topology"] = build_topology(plan, ...)   # topology_builder.py

    return plan                                    # 供 export_plan 写入 JSON + 01–04 表
```

**五阶段生成流程**（`deployment/phased_deploy.yaml`，对应 8.3.1 表 8.2）：

| 阶段 | 核心步骤 | 输出结果 | 核心规则 |
|------|----------|----------|----------|
| 阶段 1 | 全局设备清单生成 | L2 级设备配额、全局统计 | 按退服率缩放、优先级分配 |
| 阶段 2 | 区域资源调度 | L3 子区域配额、任务/制式 | L2→L3 拆解、业务匹配 |
| 阶段 3 | 设备点位生成 | 网格 + 坐标点位数据 | 12 网格分配、双模式差异化 |
| 阶段 4 | 三级拓扑构建 | 区域内/间/骨干拓扑 | Hub 选举、星型/网状混合 |
| 阶段 5 | 交付物导出 | JSON 蓝图 + 01–04 标准化表格 | 标准化格式、字段固化 |

**导出入口：** `deployment/export_plan.py`

```bash
python -m deployment.export_plan --scenario extreme_rainstorm --mode with_residual
# 或一键导出 4 套：python -m deployment.export_plan --all
```

**运行示例：**

```
[export_plan] scenario=extreme_rainstorm mode=with_residual
  output: outputs/rainstorm_with_residual/network_plan.json
  residual_nodes_reused: 32
  emergency_nodes_deployed: 16
  primary_backhaul: 5G_residual_link
  comm_modes: 5G_700MHz, Satellite_Ka, WiFi6, Shortwave_HF
  phases: 5 steps
  rl_source: hmari_checkpoint_enhanced
```

每套 outputs 目录含 **5 类交付物**：`network_plan.json` + `01_全局设备分配清单.txt` + `02_区域资源调度表.txt` + `03_子区域设备部署明细表.txt` + `04_设备点位与拓扑连接表.txt`。
