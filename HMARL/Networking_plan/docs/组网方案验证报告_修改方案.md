4. **交付物从「JSON + 三表」升级为「JSON + 四表」**，并补充拓扑生成流程。

## 八、方案生成流程（伪代码 / 代码说明）

### 7.1 `build_network_plan` 核心步骤（指标一）

**旧：**
```python
nodes, residual_count, emergency_count = _build_nodes(...)
...
return plan  # 写入 network_plan.json
```

**新：**
```python
nodes, residual_count, emergency_count = _build_nodes(...)
assign_grid_placements(plan, ...)   # deployment/grid_placement.py：网格点位
build_topology(plan, ...)            # deployment/topology_builder.py：分层拓扑
return plan                          # 写入 network_plan.json + 导出 01–04 表
```

### 7.2 场景差异化（5.2.4）

**旧：** `deployment/plan_builder.py 中按灾害类型生成不同链路特征` + `links.append({"link_type": "patch_fiber", ...})`

**新：** `deployment/topology_builder.py 在 grid 点位确定后生成分层拓扑，并按灾害类型追加场景补丁链路：`

```python
intra_links = _build_intra_region_links(...)
inter_links = _build_inter_region_links(...)
backbone_links = _build_backbone_links(...)
overlays = _scenario_overlays(scenario)
# rainstorm → patch_fiber；typhoon → local_blackout_bridge
```

### 7.3 无残余分支（5.3.4）

确认写为：
```python
emergency_base = max(emergency_base, n_regions * 4)
```
不要写 `max(emergency_base, 18)`。
