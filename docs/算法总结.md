## PPO（algos/ppo.py）
- 轻量化的 on-policy PPO 训练器，使用 `MLPActorCritic`。每轮收集 `rollout_steps` 轨迹，基于 `gamma` 与 `gae_lambda` 计算 GAE 和回报，再按 `update_epochs` × `mini_batch_size` 做裁剪概率比更新。损失由策略损失、价值损失、熵正则（`entropy_coef`）组成，并做梯度裁剪（`max_grad_norm`）。
- 结束/截断时记录奖励、覆盖率、广播率等指标，按 `log_interval` 打印均值，`eval_interval` 触发评估（可设置确定性）。最终将策略权重与训练指标保存到 `artifacts/`，并通过 `progress_callback` 发送进度事件。
- 原理：PPO 用裁剪的替代目标 `L_clip = min(r_t A_t, clip(r_t, 1-ε, 1+ε) A_t)` 控制更新步长，避免 TRPO 中的二阶约束。优势函数经标准化减少方差，熵正则鼓励探索，价值网络用 MSE 约束基线稳定性，梯度裁剪防止梯度爆炸。
- GAE：用 `gae_lambda` 在一阶 TD 误差和 Monte Carlo 之间折中，向后递推累积优势，降低高方差又保持低偏差；`gamma` 控折扣。
- On-policy：每次更新只使用当前策略采样的 rollout，保持策略-数据一致性；评估阶段可切换到确定性动作观测性能上界。

## DQN（algos/dqn.py）
- 面向大离散动作空间的分解 Q-learning。使用 `DQNNetwork`、经验回放和目标网络，支持 n-step 回报（`n_step`）并在 episode 结束时 flush 余下序列。Q 目标取目标网络的 `max_next_q`，以 MSE 损失更新；目标网络按 `target_update_period` 硬更新，否则软更新（`target_update_tau`）。
- 策略为 epsilon-greedy，`epsilon` 从 `epsilon_start` 线性衰减到 `epsilon_end`（`epsilon_decay_steps`）。达到批量后开始学习，按 `log_interval` 输出平均奖励/覆盖率与最近一次 Q 损失，`eval_interval` 评估。训练结束同样保存策略与指标。
- 原理：标准 Q-learning 的 Bellman 目标 `Q(s,a) ← r + γ max_a' Q_target(s',a')`，通过经验回放打破序列相关性，目标网络减少自举带来的估计震荡，适合大动作空间的离策略学习。
- n-step：累计 n 步折扣回报，可在高稀疏奖励或长延迟任务中加快传播；终止时 flush 缓冲，确保尾部轨迹也被学习。
- 探索：epsilon-greedy 在训练初期保持较高随机性，随步数衰减到 exploitation；评估时强制 `epsilon=0` 以衡量学到的贪心策略。

## MPPO（algos/mppo.py）
- 继承 PPO 的训练流程，配合 `MPPOPolicy`（共享骨干 + 多头 actor + 单 critic）。用于多场景/多奖励头场景，通过 `config["mppo"]` 配置超参，初始化时将 `experiment.algorithm` 设为 `mppo` 以便保存/记录。
- 原理：共享特征提取器提升样本效率，多头 actor 针对不同场景/奖励定义不同策略分布；active head 可按任务切换，保持 critic 共享以稳定价值估计。优化目标依旧是 PPO 的裁剪损失，超参读取自 `config["mppo"]`。

## A3C（algos/a3c.py）
- 同样复用 PPO 主循环，但使用 `A3CPolicy`：共享特征后输出动作 logits 及三路价值（覆盖/吞吐/成本），按权重聚合为总价值参与 PPO 更新；权重可配置并可在线更新。配置来源 `config["a3c"]`，算法标识写入 `experiment.algorithm` 为 `a3c`。
- 原理：多目标强化学习的加权和方法，设权重 `w_cov, w_thr, w_cost`，聚合值 `V_aggr = w_cov * V_cov + w_thr * V_thr - w_cost * V_cost` 作为 critic 基线；独立价值头让不同指标的梯度更可解释，可按需求调整权重以偏向覆盖或吞吐。
- 探索/优化：策略损失与 PPO 相同，优势来源于聚合值；在相同数据上同时学习三路价值，有助于后续调权或分析各指标贡献。
