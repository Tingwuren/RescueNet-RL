# 设备类型字典

本文档整理当前系统中和设备类型相关的完整枚举口径，供前端展示、平台联调、测试记录和 ns-3 场景转换时统一使用。

## 1. 拓扑节点类型

拓扑节点类型主要出现在 `scene_export.disaster_scene.nodes[].type`、`scene_export.deployment_scene.nodes[].type` 以及前端拓扑图组件中。

| 类型值 | 中文名称 | 角色 | ns-3 数值编码 | 默认在线状态 | 说明 |
| --- | --- | --- | ---: | --- | --- |
| `USER` | 受灾用户节点 | 用户终端 | `0` | 在线 | 表示灾区用户或业务终端。是否已接入网络由 `connected` 字段表达，是否被广播覆盖由 `broadcast_served` 字段表达。 |
| `MACRO_ENB` | 宏基站 | 基站节点 | `1` | 在线 | 表示宏站、应急宏站、防洪宏站、抗震宏站等广覆盖基站。 |
| `MANPACK_ENB` | 背负式基站 | 机动基站节点 | `2` | 离线 | 表示背负式、便携式、热点、短波等可快速部署的临时接入节点。当前后端场景导出中，非宏站部署节点默认归到该类型。 |
| `SMALL_CELL` | 微型基站 | 小型基站节点 | `3` | 在线 | 前端拓扑图支持的展示类型，适合表达微站、小站、热点增强节点，例如 `mmwave_micro`。当前后端导出未单独映射该类型。 |
| `RELAY` | 自组网中继节点 | 中继节点 | `4` | 离线 | 前端拓扑图支持的中继展示类型，适合表达卫星中继、跨区中继、Mesh 中继等节点。 |
| `RELAY_ENB` | 自组网中继节点 | 中继节点 | `4` | 离线 | `RELAY` 的同义类型，前端拓扑图支持。建议平台侧归一化为 `RELAY`。 |
| `RELAY_NODE` | 自组网中继节点 | 中继节点 | `4` | 离线 | ns-3 C++ 解析器当前识别的中继类型。进入 ns-3 前如使用 `RELAY` 或 `RELAY_ENB`，建议转换为 `RELAY_NODE`。 |

前端拓扑图还有两个展示态类型，不建议作为接口入参传递：

| 展示态类型 | 中文名称 | 来源 |
| --- | --- | --- |
| `CONNECTED_USER` | 正常用户节点 | 由 `USER` 节点的 `connected=true` 派生。 |
| `BROADCAST_USER` | 广播覆盖用户 | 由 `USER` 节点的 `broadcast_served=true` 派生。 |

## 4. 接口使用口径

### 4.1 查询设备库

```http
GET /api/scenarios
```

响应中的 `scenarios[].base_stations[]` 是平台侧设备列表的推荐数据源。前端不应手工维护另一套设备常量。

### 4.2 导入场景并指定残余基站

```http
POST /api/simulate/scene
```

```json
{
  "scenario_name": "typhoon_residual",
  "env_type": "multimodal",
  "custom_base_stations": [
    {
      "x": 10,
      "y": 12,
      "base_station": "macro_bs",
      "mode": "5G_700MHz"
    }
  ]
}
```

`custom_base_stations[].base_station` 必须使用第 3 节中的设备键；`mode` 应使用该设备支持的通信模式。若 `mode` 不合法，后端会回退到该设备支持的第一个通信模式。

### 4.3 执行策略仿真并查看部署动作

```http
POST /api/simulate
```

策略执行过程中的每次部署动作在响应的 `reports[0].steps[]` 中查看：

```json
{
  "step": 1,
  "action_index": 123,
  "action_desc": {
    "site_index": 5,
    "location": [10, 12],
    "comm_mode": "5G_700MHz",
    "broadcast_mode": "satellite_broadcast"
  },
  "post_state": {},
  "coverage_delta": 0.03,
  "broadcast_delta": 0.02
}
```

## 5. 当前实现注意事项

1. 当前后端场景导出的 `_base_station_node_type()` 只把名称包含 `macro` 或以 `_enb` 结尾的设备映射为 `MACRO_ENB`，其他部署设备会映射为 `MANPACK_ENB`。
2. `SMALL_CELL`、`RELAY`、`RELAY_ENB` 是前端拓扑图已支持的展示类型，但后端导出当前没有按设备键细分输出这些类型。
3. ns-3 C++ 解析器当前识别的中继字符串是 `RELAY_NODE`。平台侧如果输出 `RELAY` 或 `RELAY_ENB` 给 ns-3，建议在转换层归一为 `RELAY_NODE`。
4. `CONNECTED_USER` 和 `BROADCAST_USER` 只是前端根据用户状态派生的展示态，不属于后端接口中的正式 `nodes[].type`。
