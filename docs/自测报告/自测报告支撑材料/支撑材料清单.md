## 关键证据摘要

- 台风极端灾害场景配置来自 `data/scenarios.json`，对应 `typhoon_residual`，用户规模为 1500，满足“不少于 1200 用户节点接入”验证要求。
- 暴雨洪涝扩展场景 `flood_no_residual` 用户规模为 1280；地震残余网络场景 `earthquake_residual` 用户规模为 1360，均保留在场景配置与导出结果中。
- `artifacts/scene_exports/` 中保留了台风、洪涝、地震场景导出 JSON，可核验用户节点、基站节点和部署结果。
- `data/traces/` 中保留 5 组链路 trace：`damaged-station.trace`、`emergency-command.trace`、`flood-emergency.trace`、`mobile-patrol.trace`、`temp-relay.trace`。
- `logs/`、`.uvicorn.log` 和 `artifacts/runs/` 中保留了策略测试过程日志、训练指标、策略模型和广播结果记录。
- `测试过程截图或录屏材料/截图材料/图4-1 现有仿真平台与本系统实际数据契合度对比图.png` 从正确的中期指标自测报告 DOCX 中提取，用于补齐报告图 4-1 的截图支撑。
