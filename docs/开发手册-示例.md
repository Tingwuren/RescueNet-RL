# 二、前端开发说明

## 2.1 基本设置

### 2.1.1 工作区设置

用于区域的维护。

- 功能点：区域的增删查改

 ```

左侧区域树【调用接口】，POST /bases/area/searchTree 根据条件查询区域树
 以下两个模块，入参为空
  终端管理-终端配置  
  基本设置-工作区设置
其余模块入参增加：excludeIds = [2],排除临时区
  

右侧编辑区【调用接口】
POST /bases/area 新增区域
  位置若来源于地图，location 提交地图相关信息
  位置若为图片，mapId 为附件上传id
  
  名称：areaName 必填 20 字 
  工作区级别：areaLevel: 1：国家级； 2：省级； 3：市级； 4：县级； 5：乡级； 6：村级；
  工作区编码：areaCode: 12位行政区域编码
  类型：areaType 区域类型：1=外部区域;2=建筑物
  
GET /bases/area/{id} 获取单个区域信息
PUT /bases/area/{id} 修改区域信息
DELETE /bases/area/{id} 删除区域
  删除： 先删除子节点，才能删除父节点
  	   直接删除父节点：提醒  该节点存在叶子节点无法删除
     删除子节点，调用接口 POST /bases/area/delleteEnable 判断是否存在终端，存在提示 分区已存在设备，先修改设备分区；

底部按钮，设置为首选地图，修改或新增时，禁用此按钮，保存后激活此按钮
【调用接口】
	GET /bases/mainConfig/1
	查询当前默认首页 获得id；当获取结果为空时，后续修改id
	PUT/bases/mainConfig/{id} 修改主配置信息
 ```

## 2.2 首页 

用于广播的维护。

- 功能点：广播的增删查改

 ```

1.获取区域树填充左面板
POST /area/searchTree 根据条件查询区域树

2.获取顶部统计信息
 GET /indexs/statistic 概况统计

3.获取地图喇叭信息
 POST /indexs/tmnCoordinates/searchAll 查询终端地图位置信息信息列表-不分页
   入参 areaId 区域id

3. 右侧面板
    5.1 信息栏
        用户点击左侧终端或建筑图层图标，分别读取以下接口获取信息展示于右面板信息栏
        GET /area/{id} 获取单个区域信息
        GET /terminal/{id} 获取单个终端信息
          终端名称 terminalName
          工作区名称 area.areaName
          物理地址 physicalAddress
          资源编码 resourceCode
          外放状态 terminalConfigSet.amplifierControl 0：关，1：开
          设备状态 deviceStatus 1=在线；2=离线
          告警状态 alarmStatus 1=正常；2=告警
          告警描述 alarmDescription (仅告警状态展示，红色)低电压告警，高电压告警，信号强度告警，低温告警，高温告警
          工作情况 operativeMode 1=空闲；2=播发。
          
          其中：离线状态（deviceStatus=2 离线）不能 对讲 和 广播监听
    5.2 区域勾选
    	POST /area/searchTree 根据条件查询区域树
    5.3 终端选择
    	初始面板为空，用户切至此页面后，再用鼠标在地图中点选终端，可逐个加入列表
    5.5 开始临时广播，
        用户可设置音量，并根据相应的面板（单一终端、区域、勾选终端列表），向目标终端进行喊话广播
        POST /broadcast 新增广播
        参数
        broadcastType: 1=临时喊话；
         priorityCode:优先级，视硬件开发包API定义
         meidiaType:媒体类型，1=麦克风；
         volume: 音量 0~100
4、默认首页区域 GET /bases/mainConfig/1
 ```



# 三、后端开发说明

## 3.1 基本设置 

### 3.1.1 工作区设置

POST  /bases/area  新增区域

```
【处理逻辑】 
1、数据库表 区域（tb_geo_area） 新增基本信息
	areaName 未删除状态 信息不重复，重复提示重复信息
	areaCode 使用系统编码规则
2、关联表 位置（tb_geo_location）新增 location 结构信息 主表关联字段：location_id
3、关联表 如果建筑上传图片，地图附件 id 关联 doc_attachment 主键 附件id map_id
4、默认 del_flag 1=有效
```

GET /bases/area/{id}  获取单个区域信息

```
【处理逻辑】 
1、数据库表 tb_geo_area 关联 tb_geo_location、doc_attachment 表
2、默认 del_flag 1=有效
```

PUT /bases/area/{id}  修改区域信息

DEL /bases/area/{id}  删除区域

```
【处理逻辑】 
 无特殊逻辑，级联编辑、逻辑删除
 编辑 areaName 未删除状态 信息不重复，重复提示重复信息
```

POST /bases/area/searchTree 根据条件查询区域树

```
【处理逻辑】 
 入参 id 对应 tb_geo_area.id 级联查询全部 del_flag=1 区域数据通过 parentId 组成树状结构
```

POST /bases/area/searchAll 根据条件查询区域-不分页

```
【处理逻辑】 
入参 parentId 对应 tb_geo_area
    areaName 对应 tb_geo_area
    areaType 对应 tb_geo_area
    areaCode 对应 tb_geo_area
    locationType 对应 tb_geo_area
```

GET /bases/mainConfig/{id} 获取单个主配置信息

```
【处理逻辑】
 查询 数据库表 tb_cfg_main del_flag = 1：有效 数据；该表 del_flag = 1 只能有一条数
```

PUT /bases/mainConfig/{id} 获取单个主配置信息

```
【处理逻辑】
修改 tb_cfg_main id满足条件的数据，当id=1 时，新增 tb_cfg_main 数据
```

 POST /bases/area/deleteEnable

```
【处理逻辑】
通过入参 areaId 查询 主表为tb_tmn_terminal tb_tmn_terminal.area_id = areaId && del_flag = 1
  若结果集为空 返回 2 2=可删除
   结果集 非空 返回 1；1=不可删除
```

## 3.2 首页

GET /indexs/statistic 概况统计

```
查询逻辑
 入参：dateTime 当前时间 eg:2025-01-07 09:36:56
返回值：
 terminalTotal  数据库表 tb_tmn_terminal.del_falg = 1 有效 总数
 terminalCount   数据库表 tb_tmn_terminal.del_falg = 1 有效 且 tb_tmn_terminal.amplifier_control=1 开启 总数

 taskCount  数据库表 tb_tsk_task.start_date <= dateTime <=  tb_tsk_task.end_date 且 tb_tsk_task.del_falg = 1
```
